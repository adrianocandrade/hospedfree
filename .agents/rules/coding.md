# Coding Rules

- Follow existing Laravel, React, TypeScript, Tailwind, and shadcn patterns.
- Use `<Trans message="..." />` for visible UI strings.
- Use lucide icons for new controls.
- Prefer Tailwind semantic tokens from `common-tailwind.css`.
- Keep edits scoped and avoid unrelated refactors.
- Classify behavior as current, reusable, target, reference-only or open before editing.
- Keep MOFH behind a provider contract and keep payment separate from provisioning.
- Preserve users/workspaces and billing until a reviewed HospedFree replacement exists.
- Do not add features to inherited links, biolinks or QR Codes.
- Follow `docs/brand-hospedfree.md` and use the existing logo files in `public/images`.
- Never copy code from the old HospedFree or Bixa.
