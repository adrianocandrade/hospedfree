# HospedFree Change Workflow

1. Read `AGENTS.md` and relevant docs.
2. Classify the requested area as current, reusable, target, reference-only or open.
3. Inspect the current code before editing.
4. If using the old HospedFree/Bixa, extract requirements only; never copy code or data.
5. Preserve users/workspaces and billing unless the task explicitly designs their replacement.
6. Keep provider details behind adapters and secrets out of logs.
7. Add or update focused tests.
8. Run applicable checks and record exact results.
9. Update docs when module ownership, brand, security or operation changes.
