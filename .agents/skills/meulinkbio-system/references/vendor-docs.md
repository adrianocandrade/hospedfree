## Interpretation Rules

- Use Vebto docs to understand expected BeLink features and operations.
- Verify every vendor instruction against the local code before changing behavior.
- Treat archive upload, CodeCanyon package flow, purchase-code activation, and `/update` web updater instructions as legacy vendor-package guidance that is not applicable to this base.
- Preserve billing docs as product guidance, not license guidance.
- Do not copy full vendor pages into the repository.
