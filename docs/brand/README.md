# Marca e experiência HospedFree

Esta pasta detalha como aplicar a identidade definida em ../brand-hospedfree.md.

## Arquivos

- brand.md — posicionamento, personalidade e narrativa.
- design-system.md — tokens, tipografia, forma, estados e temas.
- content.md — voz, termos e exemplos de microcopy.
- components.md — contratos de componentes de hosting.
- site-structure.md — arquitetura proposta do site público.
- AGENTS.md — limites para autores e agentes.
- assets/README.md — classificação dos ativos herdados.

## Fonte de verdade

Quando houver divergência:

1. PRODUCT.md decide o que o produto é.
2. docs/brand-hospedfree.md decide identidade e logotipo.
3. DESIGN.md decide a experiência geral.
4. Estes arquivos detalham a aplicação.
5. O código mostra o que existe hoje.

O conteúdo desta pasta é majoritariamente alvo. Ele não deve ser usado para alegar que um recurso já foi implementado.
