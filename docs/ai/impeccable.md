# Impeccable no HospedFree

## Papel

A skill Impeccable orienta auditoria e qualidade de UI/UX. Ela não define produto ou marca sozinha.

Ordem:

1. PRODUCT.md;
2. docs/brand-hospedfree.md;
3. DESIGN.md;
4. documentação detalhada de marca;
5. código atual.

## Arquivos

Arquivos gerados ficam em:

- .agents/skills/impeccable/
- .cursor/skills/impeccable/

Não sobrescrever nem rebatizar esses diretórios manualmente. Reinstalação deve usar o fluxo oficial da skill.

## Uso no projeto

- auditar site público, painel e admin;
- validar hierarquia, estados, acessibilidade e responsividade;
- manter os logos oficiais;
- diferenciar alvo de implementação;
- evitar UI genérica de hosting e métricas inventadas;
- garantir que credenciais e provider details não apareçam indevidamente.

## Histórico

Impeccable foi instalada na base anterior. Comandos interativos da skill não são comandos shell. Nesta fase documental, ela orientou a consolidação do contrato visual; nenhum frontend foi alterado.
