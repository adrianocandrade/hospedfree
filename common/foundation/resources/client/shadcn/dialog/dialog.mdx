## Composition

Use the following composition to build a `Dialog`:

```text
Dialog.Root
├── Dialog.Trigger
└── Dialog.Portal
    ├── Dialog.Backdrop
    └── Dialog.Content
        ├── Dialog.Header
        │   ├── Dialog.Title
        │   └── Dialog.Description
        ├── Dialog.Body
        └── Dialog.Footer
            └── Dialog.CloseButton
```

## Dialog content state

If a dialog content contains any state (e.g. useForm, useState), put the state under `Dialog.Portal` so
it is automatically reset when the dialog opens and closes.

```jsx title="Dialog content state"
return (
  <Dialog.Root open={open} onOpenChange={setOpen}>
    <Dialog.Trigger>Open</Dialog.Trigger>
    <Dialog.Portal>
      <DialogContent />
    </Dialog.Portal>
  </Dialog.Root>
);

function DialogContent() {
  const form = useForm();
  return (
    <Form form={form} onSubmit={() => {}}>
      <Dialog.Content>
        <Dialog.Header>
          <Dialog.Title>Example dialog</Dialog.Title>
        </Dialog.Header>
        <Dialog.Body>...</Dialog.Body>
        <Dialog.Footer>
          <Dialog.CloseButton>Close</Dialog.CloseButton>
          <Button type="submit">Submit</Button>
        </Dialog.Footer>
      </Dialog.Content>
    </Form>
  );
}
```

## Dialog state

By default, Dialog is an uncontrolled component that manages its own state. Use `open` and `onOpenChange` props if you need to access or control the state of the dialog. For example, you can control the dialog state in order to open it imperatively from another place in your app.

```jsx title="Controlled dialog"
const [open, setOpen] = React.useState(false);
return (
  <Dialog.Root open={open} onOpenChange={setOpen}>
    <Dialog.Trigger>Open</Dialog.Trigger>
    <Dialog.Portal>
      <form
        // Close the dialog once the form data is submitted
        onSubmit={async () => {
          await submitData();
          setOpen(false);
        }}
      >
        <Dialog.Content>...</Dialog.Content>
      </form>
    </Dialog.Portal>
  </Dialog.Root>
);
```

## Migrating from legacy Modal

Replace legacy `Modal` / `DialogTrigger` with `Dialog.Root`, `Dialog.Trigger`, `Dialog.Portal`,
`Dialog.Backdrop`, and `Dialog.Content`.

```jsx title="Legacy controlled modal"
{
  isOpen && (
    <Modal isOpen={isOpen} onClose={handleClose} isDismissable={dismissable}>
      {panel}
    </Modal>
  );
}
```

```jsx title="Controlled dialog"
<Dialog.Root
  open={isOpen}
  onOpenChange={nextOpen => {
    if (!nextOpen) {
      handleClose();
    }
  }}
>
  <Dialog.Portal>
    <Dialog.Backdrop />
    <Dialog.Content>{panel}</Dialog.Content>
  </Dialog.Portal>
</Dialog.Root>
```

### Migration checklist

1. Move controlled state from `isOpen` / `onClose` to `open` / `onOpenChange`; call the old close handler when `onOpenChange(false)` fires.
2. Replace `isDismissable={false}` with `disablePointerDismissal` on `Dialog.Root`; verify Escape behavior in flows that need strict parity.
3. Map `autoFocus` to `initialFocus` and `restoreFocus` to `finalFocus` on `Dialog.Content` when needed.
4. Put form state inside `Dialog.Portal` so it resets on close; wrap `Dialog.Content` with the form instead of relying on legacy dialog context.
5. Close after submit by controlling `open`; return values from legacy `close()` and imperative `openDialog(...)` flows should become explicit callbacks.
6. Ignore legacy `type` / `mobileType`; use separate Dialog, Popover, or Drawer components instead.
7. Replace legacy `size` with responsive `className` widths on `Dialog.Content`.

### Legacy size mapping

Use `sm:max-w-*` so the dialog remains full width on narrow screens and gains a max width from the `sm` breakpoint up.

| Legacy `size`        | `Dialog.Content` `className`                                     |
| -------------------- | ---------------------------------------------------------------- |
| `2xs`                | `sm:max-w-64`                                                    |
| `xs`                 | `sm:max-w-xs`                                                    |
| `sm`                 | `sm:max-w-sm`                                                    |
| `md`                 | `sm:max-w-md`                                                    |
| `lg`                 | `sm:max-w-xl`                                                    |
| `xl`                 | `sm:max-w-3xl`                                                   |
| `2xl`                | `sm:max-w-4xl`                                                   |
| `fullscreen`         | `sm:max-w-7xl`                                                   |
| `fullscreenTakeover` | Use full-viewport classes, e.g. `h-dvh w-full max-w-none`.       |
| `auto`               | Depends on the usage, often `sm:max-w-fit` or an arbitrary size. |
